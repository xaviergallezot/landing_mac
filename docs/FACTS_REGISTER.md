# Facts Register — Registre de vérité

Ce document centralise les informations autorisées pour les contenus
publics du Method Acting Center.

## Règles

- Une affirmation importante doit avoir une source.
- Toute information temporaire doit avoir une date de vérification.
- Les données contradictoires doivent être signalées.
- Les informations incertaines restent en attente de validation.
- Aucun agent ne doit convertir une hypothèse en fait.

Statuts utilisés : **Vérifié** (source datée, confirmée par le
propriétaire ou par le site), **À confirmer** (présent sur le site mais
sans confirmation écrite du propriétaire), **À vérifier** (aucune source).

Les valeurs ci-dessous ont été pré-remplies le 2026-10-12 à partir des
sources du dépôt (`newsite/pages/*.html`, `newsite/static/llms.txt`,
`newsite/build.py`) et des informations transmises par le propriétaire
(fiche Google Business, horaires, réseaux sociaux). Elles restent
soumises à la règle ci-dessus : toute contradiction constatée doit être
signalée avant usage.

## Équipe pédagogique

Pour chaque personne :
- nom public ;
- fonction ;
- biographie autorisée ;
- expériences vérifiées ;
- source officielle ou professionnelle ;
- consentement si nécessaire ;
- date de vérification.

## Méthodes pédagogiques

Documenter séparément :
- exercices effectivement enseignés ;
- références pédagogiques revendiquées ;
- approche de Stanislavski ;
- références à l'Actors Studio ;
- autres approches éventuellement utilisées ;
- modalités du travail devant caméra.

État actuel (site, 2026-10-12) : le site revendique « la Méthode »
(Stanislavski / Actors Studio) résumée en trois temps : déclencher de
vraies émotions, les maîtriser, les reproduire avec précision. Les
exercices précis et les références détaillées ne sont pas documentés :
**À confirmer** auprès du propriétaire avant toute affirmation détaillée.

Ne pas présenter toutes ces approches comme équivalentes.

## Processus de mise à jour

1. L'agent trouve une information.
2. Il enregistre la source et la date.
3. Il signale les contradictions.
4. Le responsable humain valide les informations sensibles.
5. L'information est mise à jour dans ce registre.
6. Les pages concernées sont identifiées.
7. La modification publique attend l'autorisation nécessaire.

Tant que le statut est « À vérifier » ou « À confirmer », la donnée ne
doit pas être présentée comme un fait nouveau dans un contenu publié.
Les valeurs déjà affichées sur le site peuvent y rester, mais ne doivent
pas être reformulées ni étendues sans validation.
