# Mission : Content Strategy

## Objectif

Créer une architecture de contenus qui répond aux besoins des élèves
potentiels et explique avec précision les formations du Method Acting
Center.

Le contenu doit être humain, utile, distinctif et vérifiable.

## 1. Lire les sources

Lire :
- CLAUDE.md ;
- docs/FACTS_REGISTER.md ;
- rapports SEO et GEO disponibles ;
- pages actuelles du site ;
- programmes et documents officiels accessibles.

Aucune information absente des sources ne doit être inventée.

## 2. Construire une architecture éditoriale

Étudier l'intérêt de pages distinctes pour :

- école et présentation ;
- formation acting ;
- approche Stanislavski, si réellement enseignée ;
- jeu face caméra ;
- ateliers et stages ;
- scénario ;
- réalisation ;
- direction d'acteurs ;
- tarifs ;
- admission ;
- enseignants ;
- questions fréquentes ;
- localisation et accès ;
- témoignages vérifiés ;
- productions et projets pédagogiques.

Ne créer une page que si elle apporte une valeur réelle.
Éviter les pages quasi identiques pour chaque ville ou mot-clé.

## 3. Définir un brief pour chaque page

Créer docs/content/CONTENT_PLAN.md.

Pour chaque page :
- objectif commercial ;
- public visé ;
- intention de recherche ;
- question principale ;
- questions secondaires ;
- faits officiels nécessaires ;
- preuves à obtenir ;
- plan H1/H2 ;
- liens internes ;
- CTA ;
- risques d'affirmations non confirmées ;
- critères de succès ;
- statut : idée, brouillon, validé, publié.

## 4. Page de référence Stanislavski

Proposer un contenu pédagogique qui explique :
- le contexte historique ;
- les notions pertinentes du système ;
- les objectifs et actions du personnage ;
- les circonstances données ;
- l'écoute et les réactions ;
- les différences entre Stanislavski et les approches américaines
  du Method Acting ;
- ce qui est effectivement enseigné à l'école ;
- les limites de ce qui peut être affirmé.

Ne pas prétendre que le programme est fidèle à une méthode
particulière sans preuve officielle.

## 5. Comparatifs et prix

Les comparatifs doivent préciser :
- la date de vérification ;
- le coût total quand il est calculable ;
- les frais annexes connus ;
- la durée et le rythme ;
- les critères de comparaison ;
- les sources ;
- les données manquantes.

Ne pas déclarer le Method Acting Center « meilleur » ou « moins cher »
sans critères explicites et preuves suffisantes.

## 6. Production

Créer des brouillons Markdown dans docs/content/drafts/.

Chaque brouillon doit inclure :
- titre ;
- slug proposé ;
- intention ;
- public ;
- contenu ;
- liens vers les sources ;
- liens internes proposés ;
- CTA ;
- faits restant à valider ;
- date de rédaction.

Ne pas publier directement.
Ne pas remplacer les pages du site.
Demander validation humaine pour toute information commerciale
ou pédagogique incertaine.

## 7. Qualité

Vérifier :
- utilité réelle ;
- originalité ;
- clarté ;
- exactitude ;
- absence de répétitions artificielles ;
- accessibilité ;
- cohérence avec la marque ;
- absence de promesses exagérées ;
- cohérence des prix et programmes.

Livrer le plan éditorial et les brouillons au chef de projet.
