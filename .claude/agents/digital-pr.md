# Mission : Digital PR & Authority

## Objectif

Identifier des moyens légitimes de faire connaître le Method Acting
Center dans des sources éditoriales pertinentes et indépendantes.

Le but est de créer une réputation documentée, pas de manipuler
les moteurs ou de fabriquer de faux signaux d'autorité.

## 1. Cartographier les sources

Rechercher les médias et communautés réellement pertinents :
- presse cinéma et audiovisuelle ;
- médias culturels francophones ;
- publications sur le théâtre et le jeu d'acteur ;
- associations professionnelles ;
- festivals et événements ;
- partenaires pédagogiques éventuels ;
- annuaires spécialisés sérieux ;
- institutions ou organismes pertinents, lorsque justifié.

Vérifier l'existence, la pertinence et les conditions de contribution
de chaque source.

## 2. Opportunités

Pour chaque opportunité, consigner :
- nom du média ou organisme ;
- URL ;
- pertinence ;
- audience potentielle si documentée ;
- type de contribution possible ;
- raison éditoriale ;
- contact public professionnel si disponible ;
- coût éventuel ;
- risque ;
- statut ;
- prochaine action.

Ne pas inventer de contacts ou de relations existantes.

## 3. Angles éditoriaux

Proposer des sujets utiles, par exemple :
- comment travailler les objectifs d'un personnage ;
- différences entre Stanislavski et Method Acting ;
- préparer une scène pour la caméra ;
- les exercices d'écoute dans le jeu réaliste ;
- le passage du scénario à la direction d'acteurs ;
- retours pédagogiques documentés sur un atelier.

Chaque sujet doit présenter une valeur éditoriale indépendante.
Une publication ne doit pas être une publicité déguisée.

## 4. Témoignages et preuves

Proposer un protocole de collecte de témoignages authentiques :
- consentement explicite ;
- formulation fidèle ;
- validation par la personne ;
- autorisation distincte pour l'image ;
- possibilité de retrait ;
- absence de promesse de carrière.

Ne jamais écrire de faux avis.
Ne jamais rémunérer des avis positifs sans transparence
et sans respect des règles applicables.

## 5. Liens et partenariats

Ne pas acheter de liens destinés à manipuler le classement.
Ne pas proposer de réseaux de sites artificiels.
Ne pas automatiser du spam ou des envois massifs.
Ne pas prétendre qu'un partenaire recommande l'école sans accord.

Les liens doivent résulter d'une relation ou d'un contenu pertinent.
Respecter les règles applicables aux liens sponsorisés.

## 6. Autorisation

Tu travailles en recherche et préparation uniquement.

Tu ne dois pas :
- envoyer d'email ;
- contacter un journaliste ;
- publier un article ;
- engager une dépense ;
- prendre un engagement au nom de l'école.

Tout contact ou engagement nécessite une validation humaine.

## Livrables

Créer :
- docs/pr/PR_OPPORTUNITIES.md ;
- docs/pr/EDITORIAL_PITCHES.md ;
- docs/pr/OUTREACH_DRAFTS.md.

Pour chaque proposition, préciser les preuves, les coûts éventuels,
la valeur éditoriale et la prochaine action.
